# Email Prioritizer Assignment

For this assignment, I had to design an email prioritizer in C++ using a max heap implementation for the priority queue.

The program is currently designed to read instructions from a .txt file.
There are four possible instructions:
EMAIL, which will add a new email to the queue
NEXT, which will display the info of the next email in the queue
READ, which will remove the email at the top of the queue from the queue as if it were read
COUNT, which will display the amount of emails remaining in the queue

Once the program reaches the end of the file, it will automatically terminate.

I have included a sample test file for the program to run with.
Once the program is compiled, it can be ran using ./(executable file) sample_test.txt

I am planning on updating this program to work with other file types to make it more versatile.
