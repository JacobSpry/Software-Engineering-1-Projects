# Web Programming Lab
## [Link to the website for this lab](https://people.eecs.ku.edu/~j072s879/index.html)

In this lab, I made 5 different html files, a JavaScript file, and a php file for my KU EECS people page.

index.html is the homepage for the website and has links to each of the practice pages.

practice1.html is an about me page with a picture imported, my contact info, a link to an online cribbage website, and a link to a Veritasium video I enjoyed.

practice2.html has a short line of text with a border. There are options to change the border thickness, border color, and background color. The button calls the alert_paragraph_color() function from the functions.js file.

practice3.html takes 2 passwords from user input and passes them to the validate() function from functions.js. validate() will make sure both of the passwords are atleast 7 characters and then that they match, giving the corresponding alert for each case.

practice4.html takes a number from user input and sends it to practice4.php to create a multiplication table.

Each file contains links to the previous page for easy navigation.
